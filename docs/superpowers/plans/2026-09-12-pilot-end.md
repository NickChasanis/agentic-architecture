# Commerce Pilot Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Complete the remaining commerce pilot phases by proving a second consumer, executable coordination state, bounded multi-agent execution, recovery/adapter replacement, and an evidence-based final evaluation.

**Architecture:** Preserve the existing catalog/publication HTTP contract. Add an independent storefront consumer that depends only on the public projection, then extend the coordination laboratory with deterministic task-state and adapter conformance scenarios. Keep runtime evidence local and disposable; document production and autonomous-coordination limits.

**Tech Stack:** TypeScript/Node test runner, Fastify, PostgreSQL, Angular, Playwright, Markdown coordination artifacts, tmux-compatible shell scripts.
